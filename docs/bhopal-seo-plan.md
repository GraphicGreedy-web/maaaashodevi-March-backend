## Homepage Structure

The homepage should target brand + broad Bhopal agency intent, then hand off to service and destination pages.

Recommended structure:

1. Hero
   H1: `Maa Aasho Devi Tours - Travel Agency in Bhopal for Religious Tours and Family Yatras`

2. Short trust intro
   Mention Bhopal base, pilgrimage specialization, family support, and key destinations.

3. Core service blocks
   Link to:
   - tour agency in Bhopal page
   - religious tour packages from Bhopal page
   - Ujjain package page
   - Char Dham page
   - Kedarnath page

4. Popular departures from Bhopal
   Show package cards with internal links.

5. Why travellers from Bhopal choose you
   Use real proof:
   - years of experience
   - family-friendly planning
   - support for elders
   - organized departures
   - transparent coordination

6. Reviews section
   Add real location-rich testimonials such as `Bhopal`, `Sehore`, `Vidisha`, `Indore` where truthful.

7. FAQ section
   Answer local-intent questions:
   - Do you organize tours from Bhopal?
   - Which pilgrimage packages are available from Bhopal?
   - Can families and senior citizens join?
   - How do bookings work?

8. Final CTA
   Link to contact plus top service pages.

## Content Rules for Ranking

- Mention `Bhopal` naturally in the intro, FAQs, and CTA.
- Avoid repeating the same exact keyword unnaturally.
- Add unique copy to each page.
- Use real package details, not filler text.
- Add local trust details consistently:

  - phone
  - WhatsApp
  - operator name
  - family and senior support
